# Changelog

Все значимые изменения проекта Autograph App. Формат — [Keep a Changelog](https://keepachangelog.com/ru/), версионирование — SemVer.

## [0.2.0-mvp] — 2026-10-26

MVP-релиз к инвесторской презентации. Полный цикл: аудит → восстановление бэкенда → ребрендинг → разгрузка UI → качество → релизные артефакты.

### Бэкенд (Supabase, восстановлен и доведён до полного состояния)
- **Исправлено (критично):** облачный проект был на паузе → восстановлен; миграции 002/006/007/008/009 + storage-бакет `autographs` применены через Management API.
- **Исправлено:** миграция 007 (сообщества) содержала незакрытый `create table` — синтаксически не могла примениться нигде; файл починен и применён.
- **Добавлено:** `npm run db:health` — живая диагностика облака (REST/Auth/13 таблиц/бакет, exit-коды для CI).
- **Добавлено:** `npm run db:proof` — автоматическое доказательство WRITE→READ→UPDATE через настоящие Auth+RLS (публичная лента читается).
- **Добавлено:** Edge Function `analyze-autograph` переписана zero-dependency (Deno.serve) и задеплоена; live-тест OK.
- **Добавлено:** честный offline-режим: health-check (5с/кэш 60с) перед сетевыми вызовами — «Демо-режим» вместо вечной ошибки «проверьте подключение».

### Доставка без QR
- **Добавлено:** web-демо на GitHub Pages: https://superdanich7-jpg.github.io/autograph-app/ (авто-деплой `npm run deploy:web`).
- **Добавлено:** workflow `Deploy Web Demo` (ручной запуск), EAS-сборки в CI — только по кнопке/тегам (перестали жечь минуты на каждый пуш).
- **Исправлено:** CI был красным на каждом пуше (рассинхрон package-lock из-за мёртвой зависимости `react-native-qrcode-svg`) — локфайл регенерирован, CI зелёный.

### Брендинг и UI
- **Добавлено:** кастомные ассеты Ink&Gold (иконка/adaptive/splash/favicon, генератор `scripts/generate-assets.js`) вместо Expo-шаблона.
- **Добавлено:** шрифтовая пара Manrope + Inter (7 весов в бандле), подключена через токены темы.
- **Изменено:** профиль разгружен — hero + витрина + коллекция + 3 кнопки; второстепенное на новом экране «Ещё» (/more).
- **Изменено:** лента разгружена — поиск/фильтры/сортировка в bottom-sheet, хедер с бейджем активных фильтров.
- **Добавлено:** демо-данные помечены «ДЕМО» (друзья, переписка, лидерборд) — сид не выдается за реальную активность.

### Качество
- **Добавлено:** ESLint 9 (expo flat config) + Prettier; lint в `verify` и CI; 0 errors (108 warnings задокументированы как BUG-10).
- **Исправлено:** хуки после early-return в AchievementsSection (краш-риск); мёртвый код удалён (AnimatedPostCard, NotificationsList, StyledText-тест; −800+ строк).
- **Добавлено:** реестр багов `tasks/BUGS-REGISTRY.md` (2 fixed, 10 open с планами).
- **Тесты:** 212/212 unit (было 194 на старте цикла).

### Релизная готовность
- **Добавлено:** экран Политики конфиденциальности (/privacy) — требование сторов.
- **Добавлено:** аналитика без SDK (lib/analytics, no-op без ключа PostHog).
- **Добавлено:** Maestro e2e-сценарий питч-флоу (.maestro/pitch-flow.yaml).
- **Добавлено:** этот CHANGELOG, MIT LICENSE, тег `v0.2.0-mvp`, GitHub Release.
