# АУДИТ ДИЗАЙНА — текущее состояние (2026-10-13)

## Что уже хорошо (держать)
- Ink&Gold тема: paper/ink/gold, dark first-class — редкий уровень для MVP.
- Единый источник токенов: lib/theme.ts → ThemeContext реэкспорт (A1 закрыт).
- Примитивы: PressableScale, Chip, Button, Card, Badge, VoteButton, Toast.
- Лента: двойной тап + сердечко-spring + haptics, спор-баннер, вердикт-пилюля, скелетон-заглушки частично.
- Профиль: streak 🔥, ~$X, ShareStats, Import/Export, Communities.
- Онбординг чинит B-01, TabBar floating pill.

## Боли (почему «неудобно» с первого запуска)
1. **Нет единого hero-стиля карточки**: фото 16:9 внутри padding-карточки → «газетный» вид, а не Instagram/TikTok. Нет edge-to-edge, нет оверлея вердикта на фото.
2. **Модалки full-screen вместо шитов**: PostDetail/Comments/Profile — тяжёлые, нет свайп-закрытия, нет 3 высот (peek/half/full). Нарушение тренда 2026 bottom-sheet architecture.
3. **Онбординг статичный**: индекс-стейт без свайпа, нет FlatList-paging, нет прогресса, нет CTA «Добавить первый автограф» + демо-коллекция.
4. **Лента без режимов**: нет табов «Для вас / Подписки», нет «Вы всё посмотрели», нет pull-to-refresh с haptic-счётчиком +N.
5. **Upload — одна длинная форма**: нет 3-шагового визарда, кнопка публикации не в thumb-зоне, нет черновика-индикатора.
6. **Profile hero перегружен**: метрики в столбик, нет сетки 3-колоночной для постов, ShareStats спрятана внизу.
7. **Тапы <48**: VoteButton 42, chip-паддинги местами 36, иконки 16-18 без hitSlop. WCAG 2.2 AA не везде.
8. **Скелетоны несистемные**: есть местами, но нет FeedSkeleton/ProfileSkeleton как компонентов + shimmer.
9. **Пустые состояния разрозненные**: в ленте есть, но нет в поиске/уведомлениях/сообществах.
10. **Типографика плавает**: местами fontSize 11-13 вручную вместо typography.*, letterSpacing нет.
11. **Фото-кэш и перф**: Image без placeholder/blurhash, нет memo на карточках, длинные списки без getItemLayout.
12. **Нет «60 секунд до ценности»**: первый запуск → пустая лента → ступор. Нужны демо-посты + CTA.

Оценка: 6.5/10. До «высшего уровня» не хватает: шиты + hero-карточки + визард + скелетоны + ForYou/Following + свайп-онбординг.
