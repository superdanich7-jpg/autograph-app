# DESIGN OVERHAUL — план редизайна UI (2026-10-27)

> Основа: визуальный аудит живого web-демо (скриншоты + дизайн-критика).
> Принцип: «премиальный чернильный + золото как ОДИН акцент престижа», глубина вместо серой каши,
> герой — сам автограф. Каждый пункт D-xx = один коммит, после каждого — verify + деплой + скриншот-проверка.

## План правок (порядок = по визуальному эффекту)

- [x] **UI-10 Токены**: шкала радиусов 12/16/20/28, штрих-цвет карточек (hairline stroke), контраст-цвета текста, золото = престиж/редкость/прогресс; синий только для интерактивных действий
- [x] **UI-11 Карточка ленты**: имя 1 раз (в хедере карточки), дата 1 раз; фото в полную ширину заподлицо с краями; «Подтверждаю» — зелёная filled, «Фейк» — красная outline (главная механика — громче всех); редкость — золотой бейдж, категория — нейтральная; вердикт-пилюля упрощена
- [x] **UI-12 Таб-бар**: FAB поднят над полосой с тенью и золотым акцентом, единые подписи, явный активный таб
- [x] **UI-13 Профиль-герой**: статус-блок объединён (уровень крупно + очки, прогресс золотом, статы — сетка 4 колонок с разделителями, подписи без обрезаний, стрик — иконка пламени вместо эмодзи)
- [x] **UI-14 Плашка вердикта на фото**: прижата к углу, без зазора-«аварии»
- [x] **UI-15 Контраст**: все подписи ≥ 4.5:1 (textSecondary поднят), био 15px

## Раунд 2 — ревью основателя (2026-10-29), коммиты 7fed74b / 10c0a6a / bff916b

| Жалоба основателя (дословно) | Решение |
|---|---|
| «кнопка добавить не по центру и нужна ли она вообще внизу» | Таб-бар переписан: сплошная стандартная панель (без плавающей пилюли), 3 слота, золотой «+» строго по центру, выступает над панелью |
| «что за клуб и точно ли оно нужно» | Клуб убран из таб-бара (маршрут /community жив, вход из «Ещё» → «Клуб коллекционеров») |
| «белый фон за менюшкой» | Пилюля заменена сплошной панелью; фон `<body>` синхронизирован с темой (ThemeContext effect + брендовые цвета в +html.tsx) |
| «вверху в ленте уродски» | Заголовок «Лента» вместо «Коллекция», аватар-монограмма вместо обрезающейся плашки «Autograph Coll…», подпись только при активных фильтрах |
| «загрузка проверки подписи бесконечная» | BUG-14: runAnalysis читал imageUri из устаревшего замыкания (null при первом выборе) и делал ранний return после setIsAnalyzing(true) → спиннер навсегда. URI передан параметром |
| «у не авторизованного сохраняются все витрина лучших» | BUG-03 (UI-часть): профиль показывает только свои посты (ownerId === currentUserId): витрина, статы, коллекция, репутация. Гость видит честные нули |
| «пусть можно будет менять язык ру/en» | lib/i18n.ts (60+ ключей) + LanguageContext (AsyncStorage, авто-детект) + переключатель RU/EN в настройках профиля. Переведены: таб-бар, лента, голосование, анализ, профиль. Остальное мигрируется по мере касания |

i18n-тесты: lib/__tests__/i18n.test.ts (6 тестов — паритет ключей, интерполяция). 218/218 PASS.
