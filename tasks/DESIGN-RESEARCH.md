# UI/UX Research 2026 — синтез для Autograph App

Дата: 2026-10-13. Источники: Muzli Mobile Trends 2026, GenDesigns Social Design, ForaSoft UX Playbook 2026.

## 1. Структурные сдвиги (не визуальные)
- **Adaptive layout**: morning/commute vs weekend/explore режимы. Для нас: «Лента» (explore) vs «Моя коллекция» (manage) — разные шапки, а не одна.
- **Bottom-sheet архитектура**: вторичный контент (фильтры, комменты, детали) — в шитах, а не в полноэкранных модалках.
- **Жесты + haptics**: свайп-назад, двойной тап, long-press preview. Пальцы помнят жесты лучше, чем иконки.
- **Passkeys**: смерть паролей. У нас auth через email — добавить пометку в бэклог.

## 2. Приоритет-стек 2026 (применимо к нам)
- Non-negotiable: thumb-зона (все CTA в нижней трети), тёмная тема как first-class, холодный старт <2.5с, тап <100мс, тапы 44x44pt / 48x48dp, Dynamic Type.
- High value: жестовая навигация + haptics, bottom-sheet для вторички, «You are all caught up» разрыв в бесконечной ленте.
- Context-dependent: adaptive шапка, glass только для оверлеев на способных девайсах.

## 3. Соц-паттерны (attention loop: Create→Distribute→React→Notify→Return)
- Лента: infinite scroll + pull-to-refresh с хаптиком и «что нового» + вкладки For You / Following + микс типов контента.
- Профиль: аватар + имя + био + 3 цифры (посты/подписчики/подписки) + сетка + хайлайты; кнопка действия всегда в thumb-зоне.
- Создание: 1 тап до камеры, черновик сохраняется, прогресс-бар шагов.
- Вовлечение: двойной тап = лайк, свайп = следующее, «спорно» = дискуссия, стрики, Wrapped-статистика.
- Уважение ко времени: «вы всё посмотрели» + счётчик времени + хронологический режим на выбор.

## 4. Что болит у нас (из кода)
- Две правды о теме: lib/theme.ts vs context/ThemeContext.tsx дублируют палитру → рассинхрон светлой/тёмной.
- Синий generic (#2563EB) — «ещё одно приложение», а не премиум-коллекция (чернила/бумага/золото).
- Лента: заголовок «Коллекция» + 3 summary-карточки + ~10 чипов фильтров = когнитивная перегрузка выше сгиба.
- Карточка: бордер + маленькое фото + actions вразнобой; нет hero-изображения и оверлея-вердикта.
- Онбординг: статичные слайды без свайпа, без иллюстраций, без value за 60 сек.
- Таббар: floating pill хорош, но центральная кнопка «Добавить» не FAB — теряется главный loop Create.
- Нет press-scale анимаций, skeleton — мигание opacity, а не shimmer.
- Тапы местами <44pt, hitSlop не везде.

## 5. Решение: Design System 2.0 «Ink & Gold»
- Бренд: чернила (ink #0F172A) + бумага (paper #FAF8F4) + золото (gold #C9A227) как акцент редкости/подлинности.
- Primary остаётся синим для доступности? Нет — переходим на ink-primary + gold-accent, синий только для info.
- Токены движения: durations 150/250/350, spring presets, press-scale 0.97.
- Радиусы: карточки 20-24, пилюли full, FAB 28.
- Тени: мягкие премиальные (sm/md/lg/xl уже есть — усилить).
- Типографика: display 34/800 остаётся, добавить letterSpacing и min touch 48.
