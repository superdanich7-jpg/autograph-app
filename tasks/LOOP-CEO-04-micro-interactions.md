# LOOP-CEO-04 — Микро-взаимодействия: haptics + двойной тап = лайк

> CEO-идея #13. Дата: 2026-10. Рисерч: Instagram/TikTok — тактильность + жесты
> создают «дофаминовую петлю» и повышают время в приложении.

## Что сделано (`components/FeedPostCard.tsx`)
- **Двойной тап по фото = лайк** (как Instagram):
  - Дебаунс одинарного тапа (260мс), чтобы второй тап успел завершить лайк, а не
    открыть детали.
  - Сердечко (Animated): spring-появление + затухание, центрировано поверх фото.
  - `useNativeDriver: true` — плавная 60fps анимация.
  - Защита: гость → `onRequireAuth()`; лайк ставится только если ещё не лайкнут.
  - `useEffect` cleanup: очистка таймера при размонтировании (no memory leak).
- **Haptic-отклик** (через `lib/haptics.ts`, `expo-haptics@~15.0.8` — подтверждён в package.json):
  - Лайк → `hapticLight()`.
  - Двойной тап-лайк → `hapticMedium()`.
  - Голосование «Подтверждаю»/«Фейк» → `hapticMedium()`.
- Импорт: `Animated`, `useEffect`, `useRef` + `hapticLight/hapticMedium`.

## UX-логика (чтобы не сломать вход в детали)
- 1 тап → открывает `PostDetailModal` (через 260мс, если второго тапа нет).
- 2 тапа подряд → лайк + сердечко (одинарный тап отменяется).
