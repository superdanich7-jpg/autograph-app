# LOOP-CEO-05 — Empty-states с CTA (воронка онбординга)

> CEO-идея #10. Дата: 2026-10. Рисерч: пустой первый экран — главная точка отвала
> новых юзеров. Нужен не «тупик», а призыв к действию (CTA).

## Что сделано (`app/(tabs)/index.tsx`)
- Разделили два случая пустой ленты:
  - **Коллекция пуста** (`posts.length === 0`): иконка `sparkles`, заголовок
    «Коллекция пока пуста», текст «сообщество проверит подлинность» + **кнопка-CTA**
    «Добавить автограф» → `router.push('/(tabs)/upload')`.
  - **Фильтры ничего не нашли**: прежний «Ничего не найдено» + подсказка снять фильтры.
- Стили: `emptyCta`, `emptyCtaText`.

## Почему важно для инвестора
- Новый пользователь/гость видит понятный следующий шаг, а не пустоту.
- Сокращает путь «скачал → первый автограф» (activation).
