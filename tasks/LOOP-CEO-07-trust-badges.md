# LOOP-CEO-07 — Trust-скоринг участников (видимые уровни доверия)

> CEO-идея #12. Дата: 2026-10. Рисерч: Reddit/StackOverflow — видимый статус
> участника повышает качество модерации и вовлечённость (« social proof »).

## Что сделано
- `lib/trust.ts` (чистые функции):
  - `getTrustTier(score)` → tier + label + icon + colorHint.
  - Пороги: ≥90 Авторитет 👑 / ≥70 Эксперт 🥇 / ≥40 Проверенный ✅ / иначе Новичок 🌱.
- `lib/__tests__/trust.test.ts` — 6 тестов (границы 40/70/90, границы «ровно на пороге»,
  наличие иконки/цвета у каждого тира).
- `app/(tabs)/community.tsx`: в лидерборде у каждого коллекционера — чип уровня
  доверия (`trustChip`) по его реальному `score`.

## Почему это честно (не «фейк»)
- Очки коллекционеров (`score`) уже есть в данных сообщества — тир переиспользует их,
  ничего не выдумывая. Вес голоса пользователя (`voteWeightsByUser`) уже влияет на
  достоверность постов — видимый статус согласуется с механикой.
