# LOOP-CEO-08 — Streaks (серия дней активности) 🔥

> CEO-идея #9. Дата: 2026-10. Рисерч: Duolingo/BeReal — серии дают +30-50% к D30
> retention. Честная, оффлайн-версия стрика на основе дат постов.

## Что сделано
- `lib/stats-share.ts` → `getDayStreak(timestamps, today?)` (чистая функция):
  - Считает подряд идущие дни активности из ISO-timestamp'ов постов.
  - Если сегодня нет активности, но была вчера — серия сохраняется (не сбрасывается
    мгновенно), иначе 0.
  - Несколько постов за день не увеличивают серию (Set по «дню»).
- `lib/__tests__/stats-share.test.ts` — 7 тестов на `getDayStreak`
  (пусто/сегодня/3 дня/от вчера/разрыв/нет 2 дней/дубли в один день).
- `app/(tabs)/profile.tsx`:
  - `dayStreak = getDayStreak(posts.map(p => p.timestamp))`.
  - 4-й Stat в сетке профиля: `🔥 N` / `—` + подпись «Дней серией».

## Почему честно
- Не выдуманный Supabase-стрик, а реальная активность по датам добавления автографов.
- Работает оффлайн/в гостевом режиме. Supabase `user_stats.streak_days` остаётся для
  облачного режима (Фаза 2 — синхронизировать отображаемое значение).
