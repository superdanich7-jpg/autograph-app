# LOOP-CEO-09 — Импорт коллекции (round-trip с экспортом)

> CEO-идея #3 (часть). Дата: 2026-10. Экспорт (`ExportCollection`) уже был — добавили
> обратную операцию: перенос коллекции между устройствами/бэкап.

## Что сделано
- `lib/collection-io.ts` (чистые функции):
  - `parseCollectionImport(raw)` → `{ valid, posts, errors }`.
  - Принимает и `{ posts: [...] }`, и верхнеуровневый массив.
  - Нормализация: неизвестные category/rarity → other/common (+предупреждение),
    evidence фильтруется по белому списку, scores клампятся 0..9999,
    `description` → `caption` (совместимость со старым экспортом), имя по умолчанию.
  - Никогда не бросает исключений — удобно для UI.
- `lib/__tests__/collection-io.test.ts` — 10 тестов (битый JSON, нет массива, пустой,
  нормализация, fallback+ошибки, description→caption, кламп scores, «Без имени»,
  пропуск не-объектов).
- `components/ImportCollection.tsx`:
  - Кнопка «Импорт» → модалка с `TextInput` (multiline) для вставки JSON.
  - Живой предпросмотр: «Готово к импорту: N» (зелёный) / «Ошибка: …» (красный).
  - Кнопка «Импортировать» активна только при валидном JSON → `addPost` для каждой
    записи + Toast + Alert с итогом и предупреждениями.
- `app/(tabs)/profile.tsx`: `<ImportCollection />` рядом с `<ExportCollection />`.

## Ограничение (честно)
- Полный перенос изображений возможен только если URI/file содержатся в JSON.
  Метаданные (имя, категория, редкость, дата, доказательства) восстанавливаются всегда.
- Без `expo-document-picker` (не в package.json) — вставка JSON через модалку.
  Полноценный файловый пикер — Фаза 2.
