## Definition of Done для MVP-питча (инвесторская встреча)

1. Живое облако: регистрация → пост → голос → комментарий → читается с другого устройства.
2. Ссылка на web-демо и APK — открываются без QR и Expo Go.
3. Ни одного шаблонного ассета; шрифтовая пара; профиль и лента ≤ 3 блоков на первом экране.
4. E2E-смоук зелёный; unit ≥ 194; typecheck PASS.
5. Privacy policy доступна по URL; v0.2.0 tag + Release с APK; CHANGELOG.
