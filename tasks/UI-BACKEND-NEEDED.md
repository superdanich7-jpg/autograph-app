# UI-BACKEND-NEEDED — задачи, где нужен Founder (минимизированы)

Всё остальное из UI-BREAKTHROUGH-RESEARCH.md делается без бека.
Здесь только то, что физически требует ваших secrets/доступа/оплаты.

## B-UI-01. Серверный полнотекстовый поиск (не блокер)
- Что: поиск по подписям/знаменитостям на сервере (pg_trgm / meilisearch).
- Почему сам не могу: нужен доступ к Supabase SQL + решение о расширении.
- Обход сейчас: клиентский фильтр уже работает, для MVP хватает.
- Действие Founder: 1 SQL-миграция (выполнить в Supabase Dashboard).

## B-UI-02. Серверный push (Expo Push API)
- Что: напоминания о стрике/ответах даже при закрытом приложении.
- Почему сам не могу: нужен Expo projectId + токены + бэкенд-джоба.
- Обход сейчас: локальные уведомления (LOOP-CEO-13) уже работают.
- Действие Founder: `eas project:init` + вставить projectId в app.json.

## B-UI-03. Realtime-чат сообществ
- Что: живой чат внутри приватных сообществ (таблица messages + realtime).
- Почему сам не могу: нужна миграция 008 + включение Realtime в Dashboard.
- Обход сейчас: сообщества offline-first уже работают (LOOP-CEO-14).
- Действие Founder: применить SQL + включить Realtime для таблицы.

## B-UI-04. PNG-сертификат подлинности (красивый шейр)
- Что: рендер сертификата в PNG через react-native-view-shot.
- Почему сам не могу: нужен `npx expo install react-native-view-shot` + dev-build
  (в Expo Go может не работать) + ваша проверка на устройстве.
- Обход сейчас: SVG-сертификат + текст для шейра (LOOP-CEO-11) уже работают.
- Действие Founder: установить пакет, собрать dev-build, проверить шейр.

## B-UI-05. История цен (оценка коллекции по рынку)
- Что: реальные цены продаж (eBay / PWCC / Beckett API).
- Почему сам не могу: нужны платные API-ключи + серверный прокси (ключи нельзя в клиент).
- Обход сейчас: эвристическая оценка ~$X (LOOP-CEO-12) уже работает.
- Действие Founder: завести ключ, решить про серверный прокси.

## B-UI-06. Preview APK без QR (доставка инвестору)
- Что: `eas build --profile preview` + ссылка на установку.
- Почему сам не могу: нужен Expo-аккаунт + `eas login` под вашей учёткой.
- Обход сейчас: `npx expo start --web` для демо в браузере.
- Действие Founder: выполнить 1 команду под своим логином (инструкция в README).

Итого: 6 задач, все с рабочими обходами. Ни одна не блокирует прорыв интерфейса.
