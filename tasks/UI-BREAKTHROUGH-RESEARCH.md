# UI-BREAKTHROUGH-RESEARCH — массовый рисерч интерфейса 2026 + план прорыва

Дата: 2026-10-13. Источники: Muzli Mobile Trends 2026, GenDesigns Social App Design,
ForaSoft UX Playbook 2026, ManyPixels Social Trends 2026, Gummble Shipped Examples 2026.

## 1. Что сейчас делают топы (факты рисерча)

### 1.1 Навигация: thumb-zone + bottom-sheet архитектура
- Таббар внизу в safe-area, все ключевые действия в нижней трети экрана (ForaSoft).
- Вторичный контент — в bottom-sheet, а не в новых экранах (Muzli 2026).
- Жесты + haptic вместо кнопок «назад» там, где можно (Muzli).
- У нас: TabBar floating pill уже есть — хорошо. Но контентные экраны длинные,
  скроллятся целиком, CTA разбросаны. Нужны sticky CTA + bottom-sheet для деталей.

### 1.2 Лента: hero-карточки, «caught up», два режима
- Карточки с крупным медиа 16:10–4:3, градиент-оверлей, плавающие действия
  поверх фото (Instagram/TikTok-паттерн, GenDesigns).
- «You're all caught up» — разрыв бесконечности, уважение ко времени (GenDesigns).
- For You / Following — алгоритмическая + хронологическая (X/Twitter-паттерн).
- Pull-to-refresh с haptic и счётчиком нового (GenDesigns).
- У нас: карточка текстовая, фото маленькое, действия под фото в ряд.
  Нужен hero-редизайн карточки.

### 1.3 Профиль: витрина, а не настройки
- Шапка-витрина: аватар, имя, цифры, 1 главный CTA (GenDesigns Profile pages).
- Сетка контента, табы «Посты / О себе / Достижения», а не простыня настроек.
- Empty-state с CTA — главная точка отвала новичков (ForaSoft time-to-value 60 сек).
- У нас: профиль — простыня секций. Нужна hero-шапка + табы + sticky CTA.

### 1.4 Создание контента: мастер за 3 шага
- Time-to-first-value < 60 секунд удваивает D7 retention (ForaSoft).
- Мастер: 1) фото → 2) детали → 3) публикация. Прогресс-бар, черновик.
- Формы: autofill, крупные тапы 48dp, inline-валидация (ForaSoft).
- У нас: upload — длинная форма на одном экране. Нужен визард.

### 1.5 Онбординг: ценность, а не функции
- 3 слайда про выгоду + «пропустить» + сразу действие (ForaSoft).
- У нас: 4 слайда про функции, нет перехода к действию. Нужен редизайн.

### 1.6 Тёмная тема как first-class citizen
- Не инверсия, а отдельная палитра (Muzli 2026). У нас уже так — держать планку.

### 1.7 Motion: press-scale 0.97, 150–250ms, haptic
- Все тапы — press-scale + haptic (Muzli, ForaSoft). У нас частично — добить везде.

### 1.8 Доступность = контракт
- 48×48dp тапы, dynamic type, контраст 4.5:1 (ForaSoft, WCAG 2.2 AA).
- У нас: minTouch=48 уже есть в токенах — проверить все кнопки.

### 1.9 AI inline, opt-in, reversible
- AI-подсказки внутри флоу, можно отменить (ForaSoft). У нас AnalysisCard — ок.

### 1.10 Пустые состояния и скелетоны
- Скелетоны при загрузке, empty-state с 1 CTA (GenDesigns, ForaSoft).
- У нас: скелетоны есть в ленте, empty-states с CTA есть (CEO-05) — усилить визуально.

## 2. Новые идеи для Autograph App (ранжированы CEO-призмой)

### P0 — прорыв первого запуска (делаю сейчас, всё сам, без бека)
1. **Hero-лента**: карточка с крупным фото, градиентом, плавающими like/comment/save
   поверх фото, вердикт-пилюля, компактные бейджи. Цель: «вау» за 3 секунды.
2. **Шапка ленты**: поиск + фильтры-чипы в одну строку, sticky. Убрать простыню фильтров.
3. **Профиль-витрина**: hero-шапка (аватар, имя, стрик, 3 цифры), табы
   «Витрина / Коллекции / О себе», sticky CTA «+ Добавить».
4. **Upload-визард**: 3 шага с прогрессом (Фото → Детали → Публикация), черновик.
5. **Онбординг 2.0**: 3 слайда выгоды + CTA «Добавить первый автограф».
6. **Press-scale + haptic везде**: Button, Chip, TabBar, карточки.
7. **Empty-state 2.0**: иллюстративная иконка, 1 главный CTA, 1 вторичный.

### P1 — глубина (делаю сам, без бека)
8. **For You / Following** табы в ленте (алгоритм уже есть — recommendPosts).
9. **«Вы всё посмотрели»** разрыв ленты + кнопка «Показать сначала спорные».
10. **Detail bottom-sheet**: детали поста как sheet, а не модалка на весь экран.
11. **Dynamic type + контраст-аудит**: прогнать все textSecondary на 4.5:1.

### P2 — требуют бека / secrets (минимизированы, см. UI-BACKEND-NEEDED.md)
12. Серверный поиск, push, realtime-чат, PNG-сертификат, история цен.

## 3. План работ (agentic loops)
- LOOP-UI-01: токены 3.0 + примитивы (PressableScale, Chip, SectionHeader, EmptyState).
- LOOP-UI-02: Hero FeedPostCard + шапка ленты + For You/Following + caught-up.
- LOOP-UI-03: Профиль-витрина (hero + табы + sticky CTA).
- LOOP-UI-04: Upload-визард (3 шага) + Onboarding 2.0.
- LOOP-UI-05: detail bottom-sheet + motion/haptic-аудит + контраст-аудит.
- Каждый loop: typecheck + test + encoding + коммит + пуш.
