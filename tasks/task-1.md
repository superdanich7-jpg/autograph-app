# Task 1: QR-код для шаринга автографа

## Описание
Добавить возможность генерации QR-кода для быстрого шеринга конкретного автографа. Пользователь может отсканировать код и открыть карточку автографа в приложении.

## Acceptance Criteria
1. На экране детального просмотра автографа (FeedScreen) есть кнопка "Поделиться"
2. При нажатии открывается sharing sheet с опциями:
   - Скопировать ссылку
   - Открыть в... (native share)
   - Сгенерировать QR-код (modal)
3. QR-код содержит deep-link вида: `autograph://post/{id}` или `https://autograph.app/post/{id}`
4. QR-код генерируется на клиенте без внешних API
5. На веб-платформе QR отображается как изображение, на мобильных — совместимый с Expo Sharing

## Связанные файлы
- `app/(tabs)/index.tsx` — добавить кнопку шеринга в PostDetailModal
- `components/ShareSheet.tsx` — новый компонент
- `lib/sharing.ts` — утилиты для генерации QR и deep-links

## Зависимости
- expo-sharing (уже в package.json)
- Нет внешних зависимостей (используем qrcode библиотеку или Canvas-based генерацию)
