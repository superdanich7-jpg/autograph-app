# Task 2: Подборки (тематические коллекции)

## Описание
Добавить возможность создавать тематические подборки (коллекции) автографов. Пользователь может группировать автографы по темам: "Спорт", "Кино", "Легендарные", "На память" и т.д.

## Acceptance Criteria
1. На экране Profile есть раздел "Мои подборки" со спиком созданных коллекций
2. Можно создать новую подборку (название, описание, цвет)
3. В подборку можно добавить/убрать автограф из ленты или детального просмотра
4. Подборки отображаются в профиле с превью автографов
5. Можно делиться подборкой (шаринг ссылки)
6. Подборки сохраняются в Supabase и локально

## Связанные файлы
- `context/PostsContext.tsx` — добавить collections в state
- `app/(tabs)/profile.tsx` — раздел подборок
- `components/CollectionsList.tsx` — новый компонент
- `components/CreateCollectionModal.tsx` — модалка создания
