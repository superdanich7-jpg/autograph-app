# Task 3: Улучшить обработку ошибок

## Проблема
Много `console.warn` вместо user-friendly сообщений. Нет Toast-уведомлений.

## Решение
1. Создать Toast-компонент для уведомлений
2. Добавить ErrorBoundary на каждый экран
3. Заменить console.warn на Toast
4. Добавить fallback UI при ошибках сети

## Критерии готовности
- [ ] Toast-уведомления работают на всех экранах
- [ ] ErrorBoundary ловит ошибки и показывает fallback
- [ ] Пользователь видит понятные сообщения об ошибках
